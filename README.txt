ChartistryLab
==============

ChartistryLab is a scientific data visualization contest focused on clear,
accurate, and compelling communication of research data.

Purpose
-------

The contest invites participants to transform scientific datasets into visual
stories that help readers understand patterns, uncertainty, methods, and
results. Submissions should emphasize both visual quality and scientific
integrity.

Submission Focus
----------------

Entries may include static figures, interactive visualizations, dashboards,
notebooks, or short visual essays. Each submission should clearly document the
data source, analysis workflow, visualization choices, and any limitations.

Evaluation Criteria
-------------------

Submissions will be reviewed for:

- Scientific accuracy and appropriate data handling
- Clarity of the visual message
- Effective design and accessibility
- Reproducibility of the analysis or visualization workflow
- Creativity in communicating complex scientific information

Participation
-------------

This repository will collect contest materials, example datasets, submission
instructions, judging criteria, and selected entries as the contest develops.
